# ReMap
<img width="178" height="332" alt="remap" src="https://github.com/user-attachments/assets/5a159d2d-a3c5-4b06-8216-ed41dbffd910" />

Input rebinding tool written in Python

## Features
 - Keyboard, mouse buttons, and mouse wheel rebinding
 - Toggle and spam modes
 - Multiple profiles
 - Undo/Redo
 - Autosave

## Requirements
 - Windows
 - Python 3, and these packages:
   - keyboard
   - mouse
   - imgui_bundle

## Installation
 - Download the repository
 - Run remap.bat
   - If that fails, try remap_debug.bat
