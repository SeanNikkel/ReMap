# ReMap
<img width="178" height="332" src="https://github.com/user-attachments/assets/94fe834d-2a2c-46df-8f42-ca975c7203a7" />

Input rebinding tool written in Python

## Features
 - Keyboard, mouse buttons, and mouse wheel rebinding
 - Toggle and spam modes
 - Multiple profiles
 - Undo/Redo
 - Autosave

## Requirements
 - Windows
 - Python 3, and these packages:
   - keyboard
   - mouse
   - imgui_bundle

## Installation
 - Download the repository
 - Run remap.bat
   - If that fails, try remap_debug.bat
